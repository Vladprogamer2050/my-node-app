# ЛР №18 — модуль `os` и мониторинг в реальном времени

Скриншоты сделаны при реальном запуске кода на этом проекте (Node.js, Windows).

## Файлы

| Файл | Что показано |
|---|---|
| `lab18-os-info-head.png` | `node os-info.js` — начало вывода: информация о системе, процессоре, памяти (первые 24 строки, из-за длины вывода разбито на два снимка) |
| `lab18-os-info.png` | `node os-info.js` — конец вывода: сетевые интерфейсы, разбиение по интерфейсам, информация о пользователе |
| `lab18-os-monitor.png` | `node os-monitor.js` — живой мониторинг CPU/RAM (запущен на 9 секунд, затем снят снимок) |

## Команды для воспроизведения

```bash
node os-info.js
node os-monitor.js      # Ctrl+C для выхода
```

## Результаты (из снимков)

- Платформа: `win32`, тип ОС `Windows_NT`, архитектура `x64`, релиз `10.0.19045`
- Хост: `DESKTOP-0GI6R5I`, время работы ~3 ч 4 мин
- CPU: 12 логических ядер, AMD Ryzen 5 5600 6-Core Processor, ~3403 МГц
- Память: всего 15.93 ГБ, свободно 8.52 ГБ, занято 7.41 ГБ (46.5%)
- Сетевые интерфейсы: Radmin VPN, Ethernet 2, Loopback, Teredo (9 интерфейсов всего)
- Пользователь: `WINDOWS 10`, домашняя директория `C:\Users\WINDOWS 10`, группа `ББМО-01-23`
- Мониторинг: `CPU: 1.0% | RAM: 46.6% (8.50 ГБ свободно)` — обновление строки через `\r`
